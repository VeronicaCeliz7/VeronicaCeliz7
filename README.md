## 🎯 Sobre mí

Estoy terminando la carrera de **Analista de Sistemas** y hoy trabajo en el cruce entre **desarrollo full-stack** y **análisis de datos**. Me gusta construir productos completos: desde la arquitectura de un backend hasta el dashboard que convierte esos datos en una decisión.

Mis proyectos más grandes nacieron de necesidades reales — una plataforma de gestión municipal desarrollada **en equipo** con un flujo de trabajo colaborativo (ramas, Pull Requests, revisión de código), un sistema de trazabilidad agrícola y análisis estadísticos de producción industrial — y los llevé de punta a punta: diseño, código, deploy y documentación.

Me maneja bien tanto trabajando de forma autónoma como integrando un equipo: coordinando convenciones de código, resolviendo conflictos de nombres/estructura entre contribuidores y sacando adelante entregas con dependencias cruzadas entre frontend y backend.

### 🚀 Proyectos destacados

#### 🏙️ UrbanFlow
Plataforma de reporte de incidentes urbanos (smart city) para gestión municipal.
- **Frontend:** React + TypeScript + Vite
- **Backend:** Node.js + Express, desplegado como funciones serverless
- **Base de datos:** MongoDB Atlas
- **Autenticación:** Clerk
- **Analítica:** endpoints de BI dedicados, conectados a Power BI para dashboards en tiempo real
- Sistema de gamificación de rangos, panel de superadmin y documentación UML completa (37 casos de uso)

#### 🌾 Alfalfa Trace (Proyecto de tesis)
Sistema de gestión y monitoreo de campos y lotes agrícolas con mapas interactivos.
- **Frontend:** Leaflet + TypeScript, dibujo de polígonos sobre mapa
- **Backend:** Supabase (PostgreSQL)
- Integración con la API de AgroMonitoring para seguimiento de parcelas vía GeoJSON

#### 📊 Análisis de Producción No Convencional (YPF)
Análisis estadístico descriptivo sobre +426.000 registros de producción de pozos no convencionales en Argentina, publicado como portfolio interactivo.
- **Stack:** Python (Pandas, Matplotlib, Seaborn), HTML/CSS
- 🔗 [Ver el portfolio en vivo](https://veronicaceliz7.github.io/analisis-petroleo-no-convencional-YPF/)
